# ファイル形式検出ツール プロジェクト概要

## 1. プロジェクト概要

### プロジェクト名

**ファイル形式検出ツール（File Format Detector）**

### 概要

「拡張子を変更する = ファイル変換」という基本的な誤解を解消するための教育用Webアプリケーション。実際のファイル操作を通じて、拡張子とファイルの実際の内容は別物であることを体験的に学習できる。

### 開発期間

- **開発完了**: 既に完成済み
- **メンテナンス**: 継続中

---

## 2. 背景・課題

### 解決したい課題

1. **根本的な誤解の是正**: 「拡張子を変える = ファイル変換」という誤解
2. **基礎ITリテラシー**: ファイル名と拡張子はただの「ラベル」であることの理解
3. **実務での混乱回避**: 「このファイルをPNGにして」等の指示への正しい理解
4. **体験的学習**: 理屈だけでなく実際に確認できる学習環境の提供

### ターゲットユーザー

- **新人社員**: IT業界に入ったばかりで基礎知識が不足している方
- **非IT系職種**: デザイナー、営業、事務職でファイル操作が必要な方
- **学習者**: パソコンを覚え始めた学生・社会人
- **実務で混乱する人**: 「AIファイルをPNGにして」等の指示を拡張子変更だと誤解する方

## 3. 製品仕様

### 技術スタック

- **フロントエンド**: HTML, CSS, JavaScript（ES6+）
- **ライブラリ**: CryptoJS（MD5ハッシュ計算）
- **対応ブラウザ**: Chrome, Firefox, Safari, Edge（モダンブラウザ）
- **デプロイ**: 静的ファイル（サーバー不要）

### 主要機能

#### 3.1 ファイル形式検出機能

- **対応形式**:
  - 画像: JPEG, PNG, GIF, BMP, WebP, PSD
  - 文書: PDF
  - 圧縮: ZIP
- **検出方法**: ファイルの内部データ（ヘッダー）を解析
- **表示情報**: 実際のファイル形式、説明、バイナリデータ

#### 3.2 ファイル比較機能

- **比較項目**:
  - ファイルサイズ（拡張子変更前後で同一であることを確認）
  - MD5ハッシュ値（ファイル内容の同一性を数値で証明）
  - 実際のファイル形式（拡張子に関係なく真の形式を表示）
- **視覚的表示**: 一致・不一致の色分け表示で分かりやすく提示

#### 3.3 ユーザーインターフェース

- **ドラッグ&ドロップ**: 直感的なファイル操作（拡張子変更前後のファイルを並べて比較）
- **リアルタイム表示**: 即座に「中身は変わっていない」ことを確認
- **日本語対応**: 専門用語を避けた分かりやすい表示
- **PC・タブレット対応**: デスクトップとタブレット環境での使用に最適化

### 制限事項・仕様上の特徴

1. **Adobe Illustrator (.ai)**: 内部構造上、PDF形式として表示される
2. **Microsoft Office形式**: 内部が圧縮構造のため、ZIP形式として表示される
3. **教育上の利点**: これらの制限も「拡張子と中身の違い」を学ぶ良い例となる
4. **ファイルサイズ**: ブラウザメモリ制限内（数百MB程度）
5. **プライバシー**: ファイルはユーザーのPC内でのみ処理（外部送信なし）

## 4. 教育効果・価値提案

### 学習目標

1. **基本概念の理解**: 拡張子はファイル名の一部でしかないことの理解
2. **実務での正しい理解**: ファイル変換と拡張子変更の違いの認識
3. **体験的確認**: 実際にファイルを操作して「中身は変わらない」ことの実感
4. **指示の正しい解釈**: 実務で「○○形式にして」と言われた時の適切な対応

### 対象となる具体的な誤解例

#### よくある間違った理解

- **拡張子変更 = ファイル変換**: `.ai` を `.png` に変更すれば PNG画像になると思う
- **ファイル名 = ファイルの中身**: ファイル名を変えるとファイル自体が変わると思う
- **表示の変化 = 実際の変化**: アイコンが変わったので中身も変わったと思う

#### このツールで学べること

- **ファイルサイズ不変**: 拡張子を変更してもファイルサイズは全く同じ
- **ハッシュ値不変**: 内容が同一であることの数値的証明
- **実際の形式不変**: バイナリ解析で真の形式は変わっていないことを確認
- **OSの識別**: 拡張子はOSがファイルを識別するための「目印」にすぎない

### 実務での応用例

このツールで基礎を学んだ後、以下のような実務での正しい理解につながります：

- 「このAIファイルをPNGにして」→ 画像編集ソフトで開いて PNG形式で保存が必要
- 「このファイルの拡張子を変更して」→ ファイル名の変更であり、変換ではない
- 「なぜファイルが開けない？」→ 拡張子とファイル内容が一致していない可能性

### 従来手法との差別化

- **実体験による理解**: 説明だけでなく実際にファイルを操作して確認
- **即座の検証**: 拡張子を変更しても中身は変わらないことを数値で証明
- **安全な実験環境**: 実際のファイルを使いながらもローカル処理で安全
- **視覚的な理解**: 同一性を色分けやハッシュ値で明確に表示

- **高速処理**: 必要最小限のデータ読み取りで高速動作
- **ブラウザ対応**: 特別なソフトのインストール不要

## 10. 結論・推奨事項

### プロジェクトの価値

本ツールは**超基礎的だが重要な誤解**を解消する教育ツールとして、多くの職場で発生している「ファイル変換」関連の混乱を根本から解決できる可能性を持っている。特に、体験型学習により「理屈」ではなく「実感」として理解できる点が大きな価値となる。

### 推奨アクション

1. **企業研修での活用**: 新人研修や基礎ITスキル向上研修での導入
2. **段階的な普及**: まずは身近な職場から始めて効果を実証
3. **フィードバック収集**: 実際の使用者からの改善要望の継続的な収集
4. **成功事例の蓄積**: どのような効果があったかの具体的な記録

### 長期ビジョン

このような「当たり前だけど誤解されがちな基礎概念」を体験的に学べるツール群の第一弾として、ITリテラシー教育全体の底上げに貢献することができる。特に、非IT職種の方々のデジタル業務効率化に大きく寄与する可能性がある。

# 対応ファイル形式詳細

このドキュメントでは、ファイル形式検出ツールが対応するファイル形式と、その判定の仕組みについて詳しく説明します。

## 対応ファイル形式一覧

### 画像ファイル

| 形式 | 拡張子 | ファイルシグネチャ | 説明 |
|------|--------|-------------------|------|
| **JPEG** | .jpg, .jpeg | `FF D8 FF` | JPEG画像ファイル |
| **PNG** | .png | `89 50 4E 47` | PNG画像ファイル |
| **GIF** | .gif | `47 49 46` | GIF画像ファイル |
| **BMP** | .bmp | `42 4D` | BMP画像ファイル |
| **WebP** | .webp | `52 49 46 46` + `57 45 42 50` | WebP画像ファイル |
| **PSD** | .psd | `38 42 50 53` | Photoshop画像ファイル |

### 文書ファイル

| 形式 | 拡張子 | ファイルシグネチャ | 説明 |
|------|--------|-------------------|------|
| **PDF** | .pdf | `25 50 44 46` | PDFファイル |

### 圧縮ファイル

| 形式 | 拡張子 | ファイルシグネチャ | 説明 |
|------|--------|-------------------|------|
| **ZIP** | .zip | `50 4B 03` または `50 4B 05` | ZIP圧縮ファイル |

## 判定の仕組み

### ファイルシグネチャとは

このツールは**ファイルヘッダー（バイナリデータの最初の数バイト）**を解析してファイル形式を判定します。

**ファイルシグネチャ**（マジックナンバー）の特徴：

- ファイルの先頭に記録される固有のバイト列
- 拡張子に関係なく、ファイルの実際の内容を特定できる
- 16進数で表現される
- OSやアプリケーションがファイル形式を識別する際に使用

### 実例

```text
JPEG ファイルの場合：
FF D8 FF E0 10 00 4A 46 49 46 00 01...
^^^^^^^^
この部分で JPEG と判定

PNG ファイルの場合：
89 50 4E 47 0D 0A 1A 0A...
^^^^^^^^^^^^
この部分で PNG と判定
```

### 判定処理の流れ

1. **ファイル読み込み**: ArrayBufferとしてバイナリデータを取得
2. **先頭バイト抽出**: 最初の8バイトを16進数に変換
3. **パターンマッチング**: 既知のシグネチャと比較
4. **形式決定**: 一致した形式を返す（不明の場合は「不明」）

## 制限事項と特殊ケース

### Adobe Illustrator (.ai) ファイル

**判定結果**: PDF形式として表示

**理由**:

- Adobe Illustratorファイルは内部的にPDF形式をベースとしている
- ファイルシグネチャが `25 50 44 46` (PDF) と同じ
- これは Adobe の設計仕様によるもの

**教育効果**:

- ファイル形式の内部構造の複雑さを学習できる
- 拡張子だけでは判断できない良い例

### Microsoft Office 形式

**判定結果**: ZIP形式として表示

**対象ファイル**:

- .docx (Word)
- .xlsx (Excel)
- .pptx (PowerPoint)
- .odt, .ods等のOpenDocument形式

**理由**:

- これらのファイルは内部的にXMLファイルをZIP圧縮した形式
- ファイルシグネチャが `50 4B` (ZIP) と同じ
- 詳細な判定にはZIP内部のファイル構造解析が必要

**教育効果**:

- 現代的なファイル形式の複雑さを理解できる
- 「複合的なファイル形式」の概念を学習

### SVG 形式

**判定結果**: 不明として表示

**理由**:

- SVGはXMLベースのテキストファイル
- バイナリシグネチャが存在しない
- XMLパースが必要で処理が重い
- パフォーマンスを考慮して対象外

### その他の制限

**大容量ファイル**:

- ブラウザのメモリ制限内でのみ動作
- 数GB以上のファイルは処理に時間がかかる場合がある

**古い形式・特殊形式**:

- 対応表にない形式は「不明」として表示
- 全てのファイル形式を網羅することは技術的に困難

## 🛠️ 技術実装詳細

### ファイル形式判定関数

各ファイル形式に対応した判定関数を実装：

```typescript
// 例: JPEG判定
function isJPEG(uint8Array: Uint8Array): boolean {
  return uint8Array[0] === 0xFF && 
         uint8Array[1] === 0xD8 && 
         uint8Array[2] === 0xFF;
}

// 例: PNG判定
function isPNG(uint8Array: Uint8Array): boolean {
  return uint8Array[0] === 0x89 && 
         uint8Array[1] === 0x50 &&
         uint8Array[2] === 0x4E && 
         uint8Array[3] === 0x47;
}
```

### 判定優先順位

より具体的な形式から順に判定：

1. JPEG, PNG, GIF等の一般的な画像形式
2. PSD等の専用形式
3. PDF
4. ZIP（最後に判定、他形式との重複を避けるため）

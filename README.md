# ファイル形式理解ツール - 対応形式一覧

## 対応ファイル形式

### 画像ファイル

| 形式 | 拡張子 | ファイルシグネチャ | 説明 |
|------|--------|-------------------|------|
| **JPEG** | .jpg, .jpeg | `FF D8 FF` | JPEG画像ファイル |
| **PNG** | .png | `89 50 4E 47` | PNG画像ファイル |
| **GIF** | .gif | `47 49 46` | GIF画像ファイル |
| **BMP** | .bmp | `42 4D` | BMP画像ファイル |
| **WebP** | .webp | `52 49 46 46` + `57 45 42 50` | WebP画像ファイル |
| **PSD** | .psd | `38 42 50 53` | Photoshop画像ファイル |

### 文書ファイル

| 形式 | 拡張子 | ファイルシグネチャ | 説明 |
|------|--------|-------------------|------|
| **PDF** | .pdf | `25 50 44 46` | PDFファイル |

### 圧縮ファイル

| 形式 | 拡張子 | ファイルシグネチャ | 説明 |
|------|--------|-------------------|------|
| **ZIP** | .zip | `50 4B 03` または `50 4B 05` | ZIP圧縮ファイル |

## 判定の仕組み

このツールは
**ファイルヘッダー（バイナリデータの最初の数バイト）**
を解析してファイル形式を判定します。

### ファイルシグネチャとは

- ファイルの先頭に記録される「マジックナンバー」
- 拡張子に関係なく、ファイルの実際の内容を特定できる
- 16進数で表現される固有のバイト列

### 実例

```
JPEG ファイルの場合：
FF D8 FF E0 10 00 4A 46 49 46 00 01...
^^^^^^^^^
この部分で JPEG と判定
```

## 使用方法

1. **元のファイル**を左側のエリアにドラッグ&ドロップ
2. 同じファイルの**拡張子を変更したファイル**を右側にドラッグ&ドロップ
3. **比較結果**で以下を確認：
   - ファイルサイズ（同じ）
   - MD5ハッシュ（同じ）
   - 実際のファイル形式（同じ）

## 教育効果

このツールにより以下を学習できます：

- **拡張子≠ファイル形式**の理解
- **ファイルヘッダー**の概念
- **バイナリデータ**の基礎知識
- **ハッシュ値**による同一性確認

## 技術仕様

- **開発言語**: HTML5, CSS3, JavaScript
- **ライブラリ**: CryptoJS (MD5ハッシュ計算)
- **対応ブラウザ**: モダンブラウザ（Chrome, Firefox, Safari, Edge）
- **ファイルサイズ制限**: ブラウザのメモリ制限内

## 注意事項

- ファイルはブラウザ内でのみ処理され、サーバーに送信されません
- 大きなファイル（数GB以上）は処理に時間がかかる場合があります
- 一部の古いファイル形式や特殊な形式は「不明」と表示される場合があります

### 判定の制限事項

#### AI形式について

- **Adobe Illustrator（.ai）ファイル**は内部的にPDF形式をベースとしているため、「**PDF**」として判定されます
- これは仕様上の制限であり、AIファイルの実際の構造によるものです

#### Microsoft Office形式について

- **Microsoft Office形式**（.docx, .xlsx, .pptx など）は内部的にZIP形式で圧縮されているため、「**ZIP**」として判定されます
- これらのファイルの詳細な判定には、ZIP内部のファイル構造解析が必要になります

#### SVG形式について

- **SVG形式**は当初検討されましたが、XMLに内包される形式のため判定処理が重く、パフォーマンスを考慮して対象外としました
- SVGファイルは多くの場合「不明」として表示されます

これらの制限は、訓練用ツールとしてのシンプルさとパフォーマンスを重視した設計上の選択です。
